# 小猫桌宠（Cat Pet）

透明置顶桌面宠物：平时角落趴窝（始终清晰），互动才跑出来；含打工人 / 财务黑话与系统监控。

支持：**macOS**（命令行）· **Windows**（命令行 / exe）

## 命令行运行

### macOS

```bash
pip3 install -r requirements-mac.txt
python3 cockroach_pet.py
# 或 ./run.sh
```

### Windows

```bat
pip install -r requirements.txt
python cockroach_pet.py
REM 或 run.bat
```

按 **Esc** 退出。
- **macOS**：点一下小猫后再按字母/方向键；全局热键与菜单栏无需焦点。
- **Windows**：鼠标在小猫上（或刚点过）即可按字母键；若 pynput 不可用则回退为窗口焦点键。全局热键与托盘无需焦点。

完整操作见 [操作说明.md](操作说明.md)。

## 产品功能（v0.1–v0.5）

| 能力 | 说明 |
|------|------|
| 设置 | 工作目录下 `settings.json`（气泡、提醒、穿透、话术包、皮肤、热键、AI） |
| 进度 | `progress.json`（亲密度、成就称号、已解锁皮肤） |
| 菜单栏/托盘 | 召唤、总览、穿透、提醒、皮肤、故事/休息、AI 开关与厂商、退出 |
| 全局热键 | `Ctrl+Alt+R` 召唤 · `/` 总览 · `P` 穿透 · `S` 状态 · `B` 对喷 · `T` 故事 · `A` AI · `Q` 退出 |
| 话术包 | `packs/*.json`，可改文案后菜单「重载话术包」 |
| 监控表演 | CPU/内存高等级时旋转、缩身、特效联动 |
| 极简模式 | 默认开：菜单只留摸头/投喂/召唤/纸箱/睡觉；更多进二级菜单 |
| 首次引导 | 新用户气泡引导（欢迎 / 月结窗口 / 养生 / 互动频率 / 形象），按钮可选、8 秒可跳过 |
| 形象 | `image/*.gif` + `codex_pets/`；默认随机，可锁定 / 「下一个形象」 |
| 皮肤色调 | `=` 或菜单：`default` / `gold` / `ghost`（也可放 `skins/*.png`） |
| 猫咪互动 | 摸头踩奶、纸箱、面团、打猎/毛线、激光、观鸟、露肚、扑击；Alt/⌥ 连喵/晒太阳/抓挠/送礼/死盯/推桌/蹭头等 |
| 双宠 | 对喷时会计猫现身；月结应援降频换语气，结束后回家/睡觉有收工礼花 |
| 故事大会 | `T` / 菜单：本地或 AI 短篇连播 |
| 休息提醒 | 约每小时现身催休息；点小猫可关掉当次 |
| 养生提醒 | 护眼/喝水/伸展（默认可调间隔）；话术包 `wellness` |
| 专注番茄钟 | 菜单开 25 分倒计时：猫蹲守陪伴，结束跑来催休息 |
| 鼠标寻访 | 鼠标约 30 分钟不动会跑来找你互动（菜单可关） |
| 周期表演 | 约 45–90 秒随机动作（含舔毛）+ 闲聊 |
| 自主行为 | 无人操作时按昼夜、专注/勿扰、会议状态自行散步/发呆/瞌睡/攀爬/倒挂 |
| 会议静默 | 共享/投屏收起、截图躲闪、开会安静；散会时轻声问一句「开完了?」 |
| AI | DeepSeek / 豆包 / 千问（OpenAI 兼容）；`secrets.json` 填 Key，失败回退本地 |

配置 AI 详见 [操作说明.md](操作说明.md)。

## 打包 Windows exe

本机是 **macOS** 时，请用 GitHub Actions 在云端 Windows 上打包（推荐）：

1. 打开仓库 **Actions** → 左侧 **Build Windows EXE**
2. 点 **Run workflow**（或 push 到 `main` 自动触发）
3. 等绿勾完成后，进入该次运行页面，底部 **Artifacts** 下载 `cockroach-pet-exe`
4. 解压得到 `cockroach_pet.exe`，拷到 Windows 双击运行

若已有 Windows 电脑，也可本地打包：

```bat
build_win.bat
```

产物：`dist\cockroach_pet.exe`。

## 快捷键速查

常用：`H` 帮助 · `N` 纸箱 · `C` 回窝 · `T` 故事 · `-` 穿透 · `=` 皮肤 · `G`/`J` 打工 · `/` 监控总览 · `Esc` 退出。

点击修饰：Mac `⌘`召唤 / Windows `Ctrl+Shift`召唤；两边都是 `Ctrl`大餐、`⌥/Alt`喂食、`Shift`跳舞。猫咪专属：Mac `⌥+字母` / Windows `Alt+字母`。

详见 **[操作说明.md](操作说明.md)**。
